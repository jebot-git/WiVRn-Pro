Exact receipt-floor selection bounds over every integer phase
============================================================

The earlier 25-point grid is now closed over all 11,111,112 integer-nanosecond
shifts from 0 through 11,111,111 ns inclusive. Original receipts, runtime target
sequence, warm membership, pre-warm identity history, sufficient cadence count
and source/target constraints are fixed. Every participating eye is ready at its
own receipt, an optimistic zero receive-to-publication delay.

The encoded unrestricted optimum improves on the finite grid by 0.022604 ms;
the distinct-source optimum improves by 0.011718 ms. The latter remains above
15 ms even under this optimistic publication/ownership model. This is not a
global hardware impossibility claim: earlier transport/source receipt, changed
runtime feedback, phase outside the stated interval, different known supply or
smaller count over shorter endpoints are outside the bound. The encoded result
does not establish sub-15 ms on hardware or authorize a live selection policy.

Proof structure
---------------
For each exact warm source population, a frame becomes eligible at a selection
deadline when shift >= original_ready - original_selection. Target ceilings are
computed once from original runtime targets; identity and target order remain
fixed. These are the only phase-dependent eligibility changes. All readiness
events within the interval, plus both endpoints and original grid points, are
retained. Between consecutive events, every feasible path is unchanged and
every age in that path increases by exactly the common phase increment. Its
nearest-rank p95 therefore increases by the same increment; an event attains
the interval minimum.

Let F(s) be the exact minimum p95 at shift s. Increasing phase only expands the
eligible path set, so F(s)-s is nonincreasing wherever feasible. Consequently,
for any a <= s <= b, F(s) >= F(b) - (b-a). An exact upper endpoint optimum gives
a lower bound on every earlier candidate in that interval. Endpoint
infeasibility similarly excludes all earlier phases. The search subdivides
only intervals whose bound can improve the incumbent; equal minima retain the
earliest minimizing phase. Every candidate event is either evaluated or listed
inside an explicit interval proof whose bound still holds against the final
optimum. No interpolated grid assumption or measurement tolerance is used.

Scope inherited from receipt-floor and cardinality bounds
--------------------------------------------------------
The original warm span is 21.284347901 seconds. 1,875 choices suffice for 88 Hz
over that full span; larger counts can delete their worst-age choices down to
1,875 while preserving all modeled order/admission constraints and not worsening
nearest-rank p95. This does not cover fewer choices with shorter endpoints.
Actual pre-warm encoded/source identities cannot be reintroduced as novel.

Every eye retains its own receipt floor; pair readiness is the maximum of
participating-eye receipts, and age retains the minimum stereo-eye receipt.
Unlimited known-frame ownership, earlier use of later-observed metadata and the
fixed runtime target sequence remain optimistic. Original wait/render/fence
admission floors are respected at phase zero and all shifts are nonnegative.
Runtime rescheduling, actual submit acceptance, pose quality and optics are not
simulated. Distinct application IDs do not establish distinct input epochs.
No host/client clock subtraction or stage-percentile addition occurs.
