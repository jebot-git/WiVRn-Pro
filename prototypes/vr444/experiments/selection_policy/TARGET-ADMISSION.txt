Admission definition and exact reduction
---------------------------------------
The four declared caps are None, 0, 1 and 2. Finite cap k is

  ceiling[i] = original_predicted_target[i] + k * horizon[i]
  horizon[i] = min(original_period[i], original_target[i]-original_prior[i])

with horizon zero if the period or prior target is zero. This reproduces only
the bounded-newest target admission calculation. The closest-target trace
records max_ahead_xr_ns=0, so that field cannot be used as the alternate policy's
horizon. The original period, target and prior values have already passed the
strict candidate trace validator, including skipped-frame semantics. A zero cap
is a diagnostic target-at-or-before-runtime restriction, not the legacy closest
selector. Two horizons are an explicit relaxation.

For nondecreasing ceilings and strictly increasing selection timestamps, find
the first deadline j with frame.target <= ceiling[j]. If none exists, the frame
has no admissible edge. Otherwise pass the unchanged exact C++ solver

  effective_ready = max(hypothetical_publication_ready, selection[j]).

This is an exact edge equivalence: at every deadline i, effective_ready <=
selection[i] iff original readiness holds and target <= ceiling[i]. Receipt
timestamps and freshness scores are unchanged. The synthetic floor is NOT a
measured publication timestamp. Nonmonotonic ceilings are rejected rather than
sorted, approximated, or silently weakened. All integer domains and strict
source/deadline orders are checked.

The Python auditor rebuilds the transform, applies the original independent
cardinality certificate audit, and then directly checks every chosen original
publication-ready timestamp and target against that deadline's original ceiling.
Only the 1,900 warm deadlines are modeled; the actual pre-warm submitted prefix
is preserved. All 25 phases, five publication advances, and counts 1,900 through
1,875 are retained from the preceding model. Sampling shifts leave the original
runtime targets/horizons fixed. No runtime feedback or later upper admission
deadline is inferred.
