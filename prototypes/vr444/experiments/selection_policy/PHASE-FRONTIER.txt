FINITE POSITIVE-PHASE / EXACT-COUNT GRID -- 2026-10-09

Question
The half-period scenario missed the strict-under-15ms p95 count requirement by
16 choices at the sufficient 88Hz count. This branch checks whether another
positive sampling phase changes that result. It reuses the validated exact
cardinality solver and independent certificate auditor without modifying them.

Declared grid
25 positive-or-zero phase values: every 0.5ms from 0 through 11ms, plus the
explicit 5.555555ms and 11.111111ms reference values. Five hypothetical per-eye
publication advances: 0, 1, 2, 4 and 8ms, clipped at each participating eye's
receipt. The phase moves selection and submission together and preserves the
observed selection-to-submit gap and recorded lower admission constraints.

Each of the 125 cells solves every exact count from 1,900 down to 1,875 on the
same 1,900 warm deadlines. The actual pre-warm submission prefix is preserved.
The original span is 21.284347901 seconds, so 1,875 is a sufficient fixed-window
count for 88Hz; shorter endpoint intervals below that count remain untested.
The model retains unlimited known-pair retention, later-observed metadata and
NO future-target ceiling. These are counterfactual relaxations, not a policy.

These percentiles describe the chosen maximum-good path; they are not globally
minimized percentiles or measured improvements.

Why this does not establish the requested live result
The phase 4ms / advance 4ms path uses 236 frames before their first recorded
candidate snapshot. Its selected source-target lead relative to the original
runtime target has p95 21.829318ms, exceeding the native one-period guard for
many choices. Handle retention, ownership, revised GPU scheduling, pose quality
and runtime feedback remain unqualified. Every tested shifted submit still
precedes its original predicted display timestamp, but that prediction is not
an independently proven latest admission deadline or optical presentation.

The path contains only 1,868 distinct joined host application-frame sets among
its 1,875 encoded identities (1,867 at phase 4.5ms). Thus even its encoded-frame
cadence must not be relabeled new application-content cadence. Those host IDs
are also not simulation/input epochs. Source freshness and target constraints
need separate analysis before considering any implementable control.

This finite grid does not prove a continuous phase optimum. Negative cells
exclude only their declared exact-count model. Positive cells prove only that
the relaxed frozen model has an audited encoded-frame witness. Neither result
changes the original failed acquisition, qualification thresholds or device
state. No measurement, native change or sub15 qualification is claimed.
