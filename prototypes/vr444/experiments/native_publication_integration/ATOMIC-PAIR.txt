The caller must finish both producer uploads and retain both image leases before
calling. The codec team's separate ready collector supplies both or neither;
this method does not itself prove Vulkan completion or whole-decoder teardown.

The wrapper checks visibility, nonnull/distinct accumulators, image/view handles,
matching nonempty extents and matching sampled-color contracts. It takes the
existing shared decoder lock then exclusive frames lock and checks shutdown
and both current accumulator identities. Decoder lifetime/join still ensures
old callbacks cannot outlive/reuse a retired accumulator address.

The shared transaction helper checks eye0/1, equal frame, exact complete view
metadata including float bit patterns and vector contents (never padding),
positive receipt clocks no later than readiness, and strict frame advance
relative to every retained history item. Failure changes neither history nor
incoming readiness. Both FIFO rotations and one common readiness timestamp
complete under the same lock, then both noexcept ledger events append before
selection/checkpoint capture can resume. Evicted handles survive the lock for
feedback; feedback failure cannot relabel committed publication as rejected.

The existing per-eye publication path is unchanged. If alpha is required, the
existing selector must still find the matching alpha stream; this API publishes
two RGB eyes and does not invent a third completed image. Both decoder and
render consumers must continue retaining leases through their own completion.
