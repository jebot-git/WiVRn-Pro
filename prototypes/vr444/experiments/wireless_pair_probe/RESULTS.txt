Actual Quest CPU and Ethernet-to-WiFi branch selection, 2026-10-09
================================================================

Decision: develop RRB32 four-worker target decoding with the pinned band-view
server candidate; keep VR444/TCP as required controls and retain the two-worker
CPU alternative. The finite wireless comparison does not justify replacing TCP
with UDP, or selecting a parity/offload branch. This is further-development
selection, not a production change or strict sub15 qualification.

High-profile UDP RTTp95 improves the first repeat by0.342ms and regresses the
second by0.158ms. Low-load differences are also mixed. With only two sequential
order-balanced repetitions on this path, no compelling repeated tail advantage
supports changing the default transport. Receiver assembly is lower for UDP here,
but its start is a complete datagram receipt whereas TCP starts at the first
record-prefix byte; neither interval is the native frame-receipt gate.

Pacing limitation: sender sleeps until its next period BEFORE generating the
next synthetic pair/record list. Preparation therefore adds to the nominal
11.11ms start interval, even when network RTT is shorter. The observed86Hz high
cadence must not be attributed solely to wireless service or stop-and-wait.
It neither proves nor disproves physical90Hz capacity. Preparation-before-sleep
is a separate future control; measured source/binaries are preserved here.
This also uses one outstanding pair and100ms expiry, unlike a pipelined native
stream. Nominal offered profiles are5.572 and75.001Mbps using IPv4+UDP reference
accounting, not instantaneous shaping or observed TCP/WiFi on-wire bitrate.

Accounting, checks and scope
----------------------------
The campaign auditor independently regenerated every completed left/right source
hash, joined every complete ACK, and checked per-arm socket byte/record totals.
All970 pairs together sent81,832,620 actual application socket bytes including
both directions and framing. UDP arms alone count41,853,480bytes with28 assumed

All67 command entries and their logs,145 captured files,10 pinned implementation

executable joins, planned/executed argument lists, timeout

remain, and cannot attach a different binary to the pinned9ec qualification.
Raw artifacts remain in the root live-selection branch; this branch retains the
hash-bound structured summary and read-only reproducible auditors.

Keep these clocks separate: host server transcode, Quest private CPU decode,
sender RTT, receiver assembly, GPU image readiness/consumer and native
