Current result
--------------
No strict sub-15 ms headset result was achieved or asserted by this research.
The already-recorded live baseline remains unchanged: valid runs had p95
20.516--26.086 ms for complete-stereo earliest receipt to post-xrEndFrame at
576x640 per eye. That boundary is not optical latency. The diagnostic fifth
capture remains failed under its original trace contract and is not promoted
into performance evidence. No headset operation was performed by this team.

The strongest CPU candidate is RRB32 immutable band views with vector RGB and
four persistent workers, pinned at a55dff163e3defa5d5be2e600b8d9a7829a8f7a1.
Its same-batch captured transcode-plus-decode p95 is below the VR444 control in
all 12 pairs; individual improvements span 0.016112--0.672624 ms. These are
576x640 per-eye inputs already encoded as VR444, on the desktop host. Original
framebuffer encoding, packet delivery, GPU readiness, compositor scheduling and
the headset runtime are outside that CPU sum. Copy-removal comparisons against
the other RRB controls retain mixed tails; the result is not universal.

Wire cost prevents a blanket codec preference. Across the four captured pairs
per group, canonical RRB32/VR444 bytes are:
  Q1:     66,332 / 98,239
  Q8-a:  245,567 /182,910
  Q8-b:  194,380 /135,653
Exact Q8 means preserving the existing decoded Q8 bytes. It does not recover
original source information lost before this transcode experiment.

Transport choices remain conditional. Native batching and GSO/GRO improved the
owned loopback tests, which do not estimate physical wireless behavior. The
VXB block stream preserves canonical complete-stereo assembly, but CPU/GPU/
network overlap was not measured. VXP per-block repair has substantial parity
overhead. VWG record windows reduce offered bytes in 143/144 captured variants
against VXP, but the declared two-fragment loss matrix completed only 38/432
versus 301/432 cases. Those fixed erasures are not loss probabilities or equal
contiguous wire bursts. No repair format is promoted on bytes alone.
