RRB32 native integration contract
================================

Dedicated custom-test option; not a production codec negotiation change.
Build must combine this branch with atomic stream publication bb52541b and
staged GPU helper1b3541c9. Root owns final overlay/patch regeneration, linked
native builds, renderer teardown qualification and all device operations.

Server:
 WIVRN_CODEC_TEST=rrb32-q1 WIVRN_CODEC_TEST_Q=1
   Encode exact opaque RGB from post-foveation codec input, without VR444
   quantization. Full-frame4:4:4 control; a central10-degree region is evaluated
   separately by root against the same source. No upstream app-image claim.
 WIVRN_CODEC_TEST=rrb32-vr444 WIVRN_CODEC_TEST_Q=1..1024
   Existing GPU VR444 encode followed by pinned exact band-view RRB32 transcode.
   Q8 preserves the existing decoded VR444 RGB, not original source RGB.
 WIVRN_CODEC_TEST_COMPRESSION=none (LZ4 is already internal to RRF blocks).
 Existing frame-stride/shader/evidence options remain; live comparisons use1.

Client opt-in files:
 codec-test-payload.txt: rrb32 (default vr444)
 codec-test-rrb-workers.txt: 2 or4 (default4)
 codec-test-rrb-output.txt: cpu or staged-gpu (default cpu)
 Requires paired admission, cpu-neon backend, direct-neon kernel configuration,
 cached-copy CPU output configuration. The effective RRB implementation is
 separately logged; those legacy settings do not claim VR444 direct execution.
 Old VR444 payload mode remains an explicit fallback/control and remains usable
 by this decoder. Unsupported/malformed RRB is rejected, never silently downgraded.

Wire/private lifetime:
 WCT1 Kind4, no WPC flags, RRB1 block_rows32; <=4MP/eye, axes<=4096.
 Complete staged stereo envelopes <=262144 bytes INCLUDES both48-byte WCT headers.
 Server stages both eyes and jointly commits/discards. Distinct eye IDs0/1 are
 required. Client preflights both complete envelopes/inner grammars before any
 decoded lease. Missing/bad peer, private-slot exhaustion or upload error cannot
 publish one eye. Completed handles publish together under the stream lock.
 GPU uses checked CPU-owned residuals and staged copies, not mapped LZ4 output.
 Same application VkQueue must submit producers and all consumers. Producer fence
 completion alone is insufficient to release a submitted renderer's image lease.
 Shared result spans survive through copy/capture; image Handle owns slot/Lease
 through final renderer completion and compositor teardown drain.

Telemetry:
 effective_codec=rrb32; rrb_output=cpu|staged-gpu; rrb_generation matches both eyes.
 configured_rrb_workers=2|4; actual rrb_workers=2|4 forCPU,0 forGPU residual path.
 rrb_vector_backend=aarch64-neon forARM CPU; not_used_residual_unpack forGPU.
 cpu_vector_backend/cpu_output_mode are not_used forCPU RRB (legacy direct fields),
 and GPU uses not_used_residual_unpack/not_used. No direct-VR444 latency claim.
 pair_decode_ms is ONE shared stereo CPU preflight+workers/decompression duration,
 repeated in both records with pair_decode_scope=stereo_once_reported_per_eye.
 Deduplicate by generation+frame; never add eye values. cpu_decode_ms=0 forRRB.
 Staged GPU staging_prepare_ms includes validation, staging copy and command
 recording; staging_copy_ms=0 with staging_copy_timing_valid=false. It is not a
 pure memcpy timing. submit_fence_wait_ms is host queue-submit+producer-fence wait;
 no device timestamp claim (gpu_timing_valid=false).
 rrb_pair_rejected is a server telemetry control row with frame/eye, pair_cap,
 staged_pair_bytes and reason=cap_exceeded|incomplete_or_invalid_pair|
 batch_failed_or_unsubmitted. The latter two can be <=cap, including0. It is not
 an encoded frame record. Failed/missing/over-cap pairs send neither staged eye.

Captures/reference:
 Every encoded frame whose index is divisible by90 writes source .rgba, payload .payload and independent
 .reference.rgba. q1 reference is source; vr444 reference is original VR444 CPU
 reconstruction. Client CPU capture_source=rrb_pair_cpu_output; staged GPU capture
 source=rrb_gpu_image_readback reads the actual private GPU image, then restores
 shader-read layout before publication. GPU readback/capture cost is diagnostic.
 Offline rrb_reference.cpp independently inspects saved payloads then scalar
 reconstructs exact RGBA, separate from native worker scheduling and GPU shader.
