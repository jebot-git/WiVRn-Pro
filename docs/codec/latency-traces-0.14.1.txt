The readiness age uses latest-eye readiness to selection end. All selection
statistics above use first unique submissions after the two-second warmup.
The closest-target policy was independently replayed and matches every record;
there are no recorded fallback or repeated selections. All 6167 records report

prediction. CPU newest-minus-selected targets are typically about 11.1 ms.
This is actual availability at the selection instant, not hindsight from frames
that arrived later. It does not establish an 11.1 ms achievable latency saving.

Latency remains mission critical
Custom repeat A: receive-to-submit p50/p95/p99 = 21.134/27.296/29.891 ms,
89.260 unique stereo submissions/s; fails all three latency limits.
Custom repeat B: 16.372/21.500/23.691 ms, 88.847 submissions/s; fails p95.
Limits remain 17/21/25 ms and at least 88 Hz. Measurement is earliest packet
receipt across the stereo pair to the observation after successful xrEndFrame,
headset-local clock. It excludes host processing and earlier transfer, and is
not motion-to-photon. Trace I/O occurs after the submit observation and can
perturb subsequent scheduling; it cannot be subtracted to manufacture a result.
Trace write medians are about 0.12–0.13 ms. These diagnostics do not supersede
the untraced 0.13.1 comparison or demonstrate an optimization speedup.

Interpretation and next implementation work
1. Instrument application-frame generation and compositor latch mapping before
   using encoded frame IDs as scene freshness. The host can reuse a projection
   layer in multiple encoded frames; source display targets are predictions.
2. Prepare a test-only bounded latest-complete selection option, preserving
   frame/warp identity, alpha requirements, fences and ownership. Record both
   closest-target and alternative decisions, future-target distance and actual
   app-generation mapping. Keep the production/default choice unchanged.
3. Compare untraced baseline/alternative repeats only after correctness checks;
   assess pose alignment, stereo stability, missed deadlines, tail latency and
   representative moving content. A newer encoded frame alone is insufficient.
4. Keep direct-to-mapped-staging decode experimental: prior 0.14.0 standalone
   median savings were about 0.23–0.25 ms, with tail regressions. It has not been
   integrated into or measured by these live runs.

Limits
One HEVC reference is not a repeated native comparison. This round contains no
new H.264 run. Native surface pixel quality is not measured here; custom sampled
CPU output correctness is not final compositor/display quality. No optical rig,
representative VR corpus, source-input timestamp or synchronization uncertainty
bound is available. The full 930-run suite is not qualified. Release readiness
and promotion eligibility remain false. No root/presence/clock overrides used.
