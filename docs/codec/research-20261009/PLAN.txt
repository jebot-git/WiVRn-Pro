Evidence rules
Measured events, counterfactual replay, local CPU/GPU experiments and future
headset hypotheses are reported separately. Never add independently computed
percentiles to infer a percentile of total latency. Lower byte counts alone do
not establish lower frame age. Higher frame IDs do not establish new input state.
Host extension availability is not Quest support. A desktop benchmark is not a
headset result. Diagnostics remain ineligible for promotion.

Offline suite readiness
The shared suite must cover current Python validators and control logic, C++
stereo admission/selection/trace contracts, mapped-output bounds, and every new
candidate's independent correctness oracle and malformed/lifetime cases. Compile
against the exact source-overlay snapshot rather than a hidden mutable worktree.
Missing prerequisites, no collected tests, timeout and process failure cannot
become passes. Receipts bind source and outputs. Run meaningful regression checks
after changes; repeat performance work only for new hypotheses or controlled
comparisons, not to select a favorable result.

Before any later headset suite is proposed as ready, require explicit trace
contract resolution, reviewed candidate code, complete source/build provenance,
at least two independently useful candidate implementations or evidence-backed
rejections, documented capability/format negotiation, clean offline checks, and
a bounded case order with baseline/repeats, cleanup and stop conditions. The
user's suspension remains in force even if those prerequisites are reached.

Open gates after this work

The strict CPU target, original cadence/tail constraints and existing full
